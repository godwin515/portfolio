# Godwin Nsikan Udosen — Portfolio

Personal portfolio website of **Godwin Nsikan Udosen**, a full-stack developer based in Nigeria.

**Live site:** https://godwin-udosen.godwinnsikan.workers.dev/

## Pages

- **Home** — introduction and featured projects
- **Projects** — case studies of live client and organisation websites
- **About** — background and technical skills
- **Contact** — email, WhatsApp and profile links

## Featured projects

| Project | Description | Stack |
|---|---|---|
| [Orlu Land Compendium](https://www.orlulandcompendium.com) | Community platform with an admin dashboard and REST API | Python, FastAPI, JavaScript, Cloudflare Pages, Render |
| [New Heaven Secondary School](https://nsikan-godwin.onrender.com) | School website with online admissions and a student portal | Python, Django, Render |

## Built with

- HTML5, CSS3 and vanilla JavaScript (no frameworks, no build step)
- Responsive, mobile-first layout with a slide-out mobile menu
- Accessible markup: semantic HTML, skip link, keyboard-friendly navigation
- Hosted on Cloudflare Pages

No installation needed. Clone the repository and open `public/index.html` in your browser:
